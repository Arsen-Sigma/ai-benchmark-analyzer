# 🤖 AI Benchmark Analyzer

> 🚀 **This is my fourth Python project.**

A console-based Python application for analyzing AI benchmark models, performance, costs and statistics.

---

## 📖 About the Project

**AI Benchmark Analyzer** is a console application written in Python that works with real AI benchmark data.

The program allows users to browse models, view top rankings, search and compare models, view detailed statistics, analyze database information and export data.

This project was created as part of my Python learning journey and helped me practice working with real data, APIs, JSON, functions, data processing and error handling.

---

## ✨ Features

- 🏆 Browse AI models
- 🥇 View top rankings
- 🔍 Search models
- ⚔️ Compare models
- 📊 View model details and statistics
- 📈 View database performance statistics
- 💰 Analyze cost and performance
- 📁 Export data
- 🌐 Fetch data from a JSON API
- 🧮 Process and analyze benchmark data

## 🚀 How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in the terminal.
4. Run the application:

    python core/main.py

---

## 🎮 How to Use

After starting the application, the main menu will appear:

    1. Browse Models
    2. Top Rankings
    3. Search Models
    4. Compare Models
    5. Model Details
    6. Statistics
    7. Export Data
    8. Database Information
    9. Exit

Enter the number of the option you want to use and follow the instructions displayed in the terminal.
